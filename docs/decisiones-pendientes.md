# Decisiones técnicas por validar

- Cómo se envía y valida un escaneo QR: servicio externo ligero, conexión local o alternativa.
- Ventana temporal del QR, firma/nonce y prevención de repetición y reuso.
- Alternativas de infraestructura compatibles con uso institucional y presupuesto.
- Qué operaciones del docente funcionan offline y cómo se reconcilian.
- Almacenamiento de asistencia, exportaciones, respaldo y recuperación.
- Modelo y permisos por usuario, curso, sección y sesión.
- Política de conservación de datos, consentimiento/autoridad y controles locales aplicables.
- Formato de plantilla institucional para reportes.
